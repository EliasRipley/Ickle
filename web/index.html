TRACKERLESS · PUBLIC · OPT-IN

Public Ickle swarm

Find other Ickle nodes through the decentralised BitTorrent DHT, then exchange signed models, training and shared reviews directly. There is no Ickle account or central peer directory.

What becomes public: joining announces this node's public IP and swarm port, as every torrent-style network must. Prompts, chats, local reviews and model files are not placed in the DHT.

Direct peer connection Advanced / private networks

Add a specific node when you want a private bootstrap, are on the same LAN, or the public DHT is blocked.

Advanced: centralized training coordinator

A separate, CLI-only way to federate full training rounds across devices through one coordinator, instead of the peer-to-peer sharing above. Set up with python -m src.app federated-server / federated-client. This just shows its status if you're already running one.

Peer teaching (co-distillation): Ickle's federated training above only pools peers running the exact same model architecture. This lets any peer running "infer serve" -- whatever size or shape their model is -- contribute candidate answers. Agreement can filter obvious outliers, but no longer creates trust by itself; candidates still pass the normal review/rollback safety checks before anything is learned.
