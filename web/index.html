Peer teaching (co-distillation): Ickle's federated training above only pools peers running the exact same model architecture. This lets any peer running "infer serve" -- whatever size or shape their model is -- teach yours instead, by asking a shared question set and only keeping answers multiple peers agree on. Nothing is trusted blindly: agreed answers still go through the normal review/rollback safety checks before anything is learned.
