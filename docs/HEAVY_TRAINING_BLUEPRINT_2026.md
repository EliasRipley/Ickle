# Heavy-training blueprint

Ickle’s present checkpoints are small local models. Reaching frontier-level capability is a long-term research and infrastructure goal; the repository does not yet demonstrate that capability.

The next credible milestones are:

1. Establish versioned, licensed, provenance-rich corpora and contamination-resistant evaluation sets.
2. Make every local and federated run reproducible from a signed manifest containing base hash, tokenizer hash, code version, data recipe, seed, and resource budget.
3. Gate every promotion on general ability, specialist gain, regression, safety, and privacy evaluations.
4. Strengthen participant identity/reputation, secure aggregation, differential-privacy options, NAT traversal, and coordinator failover.
5. Move mobile training to battery/thermal-aware scheduled work and benchmark energy per useful accepted update.
6. Scale model size only after the learning signal, evaluation, and recovery paths are reliable.

Environmental benefit must be measured rather than assumed. Report energy used per run, hardware class, useful-update acceptance rate, and avoided transfer/storage where possible.
